# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link applies to all project spaces (issues, pull requests,
discussions, review comments).

In short:

- Be respectful and welcoming. Give and accept constructive feedback.
- No harassment, discrimination, personal attacks, trolling, or publishing others'
  private information.
- Maintainers may edit, remove or reject contributions and may restrict participation
  that does not follow this code.

## Reporting

There is no email contact. Report a violation by:

- opening a GitHub issue, if the report can be public; or
- using a private GitHub security advisory
  (<https://github.com/dorel14/libembedding-ng/security/advisories/new>) when the
  report must stay private.

Maintainers will review and respond in good faith and will respect the privacy of
the reporter.
